# ADR 0012: agent-ready product name

Status: accepted.
Implementation: partial.

The project uses **Vinext Laravel Starter** as its public name and `vinext-laravel-starter` in repository and package identifiers. "AI" was removed because the running application deliberately has no AI provider or AI behavior; the differentiator is a Laravel and Vinext foundation designed to be developed safely with coding agents. The renamed package restarts at v1.0.0 because the original package has no consumers. The legacy releases and tags have been removed; Packagist retirement remains part of the v1 publication cutover.
