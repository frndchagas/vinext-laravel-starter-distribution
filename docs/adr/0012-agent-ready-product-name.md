# ADR 0012: agent-ready product name

Status: accepted.
Implementation: complete.

The project uses **Vinext Laravel Starter** as its public name and `vinext-laravel-starter` in repository and package identifiers. "AI" was removed because the running application deliberately has no AI provider or AI behavior; the differentiator is a Laravel and Vinext foundation designed to be developed safely with coding agents. The package restarted at v1.0.0 because the original package had no consumers. The v1 cutover renamed both GitHub repositories, removed the legacy releases and tags, published the new Packagist package and retired the unused package name.
