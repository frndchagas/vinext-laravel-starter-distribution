# ADR 0011: layered, task-oriented documentation

Status: accepted.
Implementation: complete.

Documentation prioritizes people evaluating or adopting the starter. The README remains a short entry point, guides describe current behavior by user task, and ADRs hold architectural decisions, including accepted work that is not implemented yet. Each fact has one canonical source. Current documentation stays below 7,000 words until production and authentication work requires more detail. A new guide should replace an equal amount of duplicated or obsolete text.
